# 네이버 블로그 에디터에 입력하고 임시저장하기

대표님 PC의 브라우저를 조작하는 방식이다. 네이버 화면이 바뀌면 아래 내용이 어긋날 수 있으니, 항상 실제 화면을 보고 맞춰서 진행한다.

## 시작 전

1. 완성된 초안(제목, 본문, 태그)이 있는지 확인한다. 대표님이 내용을 한 번 보셨는지도 확인한다.
2. 대표님 기본 브라우저에 맞는 스킬(`built-in-browser` 또는 `chrome-browser`)을 읽는다.
3. 사진 파일이 있다면 어디에 있는지 확인한다.

## 순서

1. **로그인 확인.** 블로그(blog.naver.com/itsshow001)를 열어 로그인된 상태인지 본다. 로그인이 안 되어 있으면 대표님께 직접 로그인해 달라고 부탁하고 기다린다. 아이디·비밀번호·인증번호는 요청하지도 입력하지도 않는다.
2. **글쓰기 화면 열기.** 보통 `https://blog.naver.com/itsshow001?Redirect=Write` 로 바로 열린다. 안 열리면 블로그 상단의 '글쓰기' 버튼을 누른다.
3. **팝업 정리.** "작성 중인 글이 있습니다"나 도움말 팝업이 뜨면, 이어쓰기 여부는 대표님께 물어보고 도움말은 닫는다. 이전 임시저장 글을 덮어쓰지 않는다.
4. **제목 입력.** 제목 칸에 선정한 제목을 입력한다.
5. **본문 입력.** 단락 단위로 나눠 입력한다. 한 번에 너무 길게 넣으면 일부가 빠지는 일이 있다. `■`로 표시한 소제목은 글자만 입력하고, 서식(굵게, 크기)은 대표님이 에디터에서 주도록 둔다. 입력 후 화면 내용을 읽어 빠진 부분이 없는지 확인한다.
6. **사진.** 업로드할 수 있는 도구와 파일 접근이 있으면 `[사진N]` 자리에 올린다. 안 되면 `[사진N: 설명]` 문구를 그대로 두고 대표님이 올리시게 안내한다.
7. **임시저장.** 상단의 '저장'(임시저장) 버튼을 누르고, 저장 완료 표시가 뜨는지 확인한다.
8. **발행은 하지 않는다.** '발행' 버튼과 예약 발행은 누르지 않는다.
9. **보고.** 화면을 확인한 뒤 "임시저장 완료. 제목은 ○○, 사진 N장은 직접 올려주세요(해당 시). 태그는 발행할 때 아래 목록을 넣어주세요"라고 알린다. 카테고리·태그·공개 설정은 발행 단계에서 정하는 구조이므로 목록으로 전달한다.

## 막혔을 때

- 같은 동작이 2~3번 안 되면 멈춘다. 계속 시도하지 않는다.
- 복사해서 붙여넣을 수 있도록 제목, 본문, 태그를 구분한 텍스트 파일로 전달하고, 대표님이 에디터에 붙여넣는 방법을 한 줄로 안내한다.
- 대화창이나 경고창(alert)이 뜨는 동작은 피한다. 브라우저 조작이 멈출 수 있다.
