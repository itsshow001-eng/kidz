# 월별 시즌 흐름 (참고용)

키즈공연 문의는 행사 시즌보다 **한두 달 앞서** 몰리는 경향이 있다. 그래서 시즌 글은 행사 시기보다 먼저 올린다. 아래는 일반적인 흐름이므로, 대표님의 실제 ERP 일정(어느 달에 공연이 많았는지)과 문의가 들어온 시기로 보정한다.

| 달 | 현장에서 많은 행사 | 이 달에 올리면 좋은 글 (다음 시즌 대비) |
|---|---|---|
| 1월 | 졸업식·종업식 준비, 설 연휴 행사 | 졸업·종업식 공연 정보글, 신학기 행사 섭외 안내 |
| 2월 | 졸업식·종업식, 신학기 준비 | 3월 입학·개학 행사, 봄 축제 상품 소개 |
| 3월 | 입학·개학, 어린이집·학원 봄 행사 | 5월 어린이날·가정의 달 섭외 정보글 |
| 4월 | 봄 소풍·봄 축제 | 어린이날 섭외 마감 임박 안내, 여름 행사 소개 |
| 5월 | 어린이날·가정의 달 (성수기) | 후기 몰아서 정리, 여름방학 프로그램 소개 |
| 6월 | 여름 축제 준비, 방학 전 학원 행사 | 여름방학 도서관·문화센터용 정보글 |
| 7~8월 | 여름방학, 물놀이·여름 축제 | 가을 축제·운동회 섭외, 후기 |
| 9월 | 추석, 가을 소풍·운동회 | 가을 축제 상품 소개, 재롱잔치 섭외 시작 안내 |
| 10월 | 가을 축제 (성수기) | 재롱잔치·송년 행사 섭외 정보글 (문의 집중 시작) |
| 11월 | 재롱잔치·크리스마스·송년 행사 섭외 집중 | 겨울 테마 상품 소개 (키즈니버스 더윈터 등 겨울과 어울리는 테마), 후기 |
| 12월 | 재롱잔치·크리스마스 공연 (성수기) | 졸업·신년 행사 섭외, 한 해 후기 모음 |

## 시즌 밖에서 꾸준히 쓸 수 있는 소재

- 공연 후기 (가장 믿을 만한 소재라 달마다 꼭 넣는다)
- 공연 종류별 소개 (버블아트, 벌룬아트, 그림자아트, 매직쇼)
- 기관 유형별 정보글 (어린이집, 유치원, 태권도장, 영어학원, 도서관, 지자체 축제)
- 공연자 이야기, 준비 과정, 재방문 고객 사례 (재방문 연계를 중요하게 생각하므로)
