# 글 종류별 구조

글 종류마다 읽는 사람의 목적이 다르다. 구조는 뼈대일 뿐이니 재료에 맞게 줄이거나 바꿔도 된다. 단, 어느 종류든 사실만 쓰고, 문의 안내로 끝낸다.

## 1. 공연 후기·현장 스토리

- **읽는 사람과 목적**: 비슷한 행사를 준비하는 담당자가 "이 팀이 실제로 이런 공연을 잘 해냈구나"를 확인한다. 신뢰와 실적의 역할.
- **제목 예**: `[지역] [기관 유형] [공연 종류] 공연 후기 | 한 줄 포인트`
- **구조**
  1. 도입 2~3문장: 언제, 어디서, 어떤 공연이었는지
  2. 공연 구성: 어떤 순서로 무엇을 보여드렸는지
  3. 현장 순간 1~2개: 재료(메모·사진)에 있는 장면을 중심으로. 분위기 묘사는 자유롭게, 특정 발언·사건은 재료에 있는 것만
  4. 담당자가 궁금해할 정보: 진행 시간, 인원 규모, 공간 조건 (재료에 있을 때만)
  5. 마무리: 비슷한 행사 문의 안내 + 연락처
- **사진**: 3~6장. 본문 사이에 `[사진1: 장면 설명]`으로 자리를 표시한다.
- **주의**: 기관명은 기본 익명. 반응·에피소드를 부풀리지 않는다.

## 2. 공연 상품 소개

- **읽는 사람과 목적**: 어떤 공연을 고를지 비교하는 담당자. 문의 전환의 역할.
- **구조**
  1. 이런 행사에 어울려요 (어린이집 행사, 축제, 학원 등)
  2. 공연 구성과 소요 시간 (키즈니버스는 약 50분)
  3. 아이들이 어떻게 참여하는지
  4. 필요한 공간·준비물 (재료에 있을 때만)
  5. 다른 구성과 조합 가능 (콜라보 공연: 1~2가지 조합)
  6. 문의 안내
- **주의**: 금액은 쓰지 않는다 ("견적은 문의해 주세요"). '단독 공연' 대신 '콜라보 공연'. 키즈니버스는 이름보다 내용을 먼저 설명한다.

## 3. 행사 담당자용 정보글

- **읽는 사람과 목적**: "어린이집 재롱잔치 공연 섭외", "축제 어린이 공연 고르는 법"처럼 검색해서 들어오는 사람. 검색 유입의 역할이고, 광고 티가 짙으면 바로 나간다.
- **구조**
  1. 담당자가 흔히 겪는 고민으로 시작
  2. 체크리스트 5~7개 (섭외 시기, 공연 시간·아이 연령에 맞는 구성, 공간·음향·전기, 안전, 사전 협의 사항 등), 항목마다 한두 단락의 이유와 요령
  3. 경험에서 나온 사례: 재료가 있을 때만
  4. 마무리: 상담 문의 안내. 자랑보다 도움이 먼저다.
- **안전 항목 팁**: 버블은 바닥이 미끄러워질 수 있고, 벌룬은 라텍스 알레르기 확인이 필요하다는 식의 현장 감각이 있는 내용이 믿음을 준다. 법규·안전 기준 수치는 출처 확인 전에는 단정하지 않는다.
- **주의**: 통계·기준 수치를 지어내지 않는다.

## 4. 소식·공지

- **읽는 사람과 목적**: 기존 고객과 관심 있는 방문자. 활동하고 있다는 신호와 새 소식 전달.
- **구조**: 짧게(500~800자). 무엇이(새 공연, 시즌 안내, 홈페이지·제안서 변경) / 언제부터 / 누구에게 해당 / 문의 방법. 사진 1~2장.
- **주의**: 홈페이지 주소와 제안서 다운로드 같은 항목은 확인된 것만 쓴다.

## 5. 예정 공연 안내 (준비 중인 공연 예고)

- **읽는 사람과 목적**: 같은 시기 행사를 고민하는 담당자와 기존 고객. 지금도 활발히 활동하는 팀이라는 신호를 주고, 문의를 이끈다. 공연이 끝나면 같은 소재로 후기를 이어 쓸 수 있다.
- **제목 예**: `[시기] [지역] [행사 유형] [공연 종류], 이렇게 준비하고 있어요` (예: "11월 천안 가을 축제 벌룬 버블 공연, 이렇게 준비하고 있어요")
- **구조**
  1. 도입: 어떤 행사에서, 대략 언제, 어떤 공연을 하게 되었는지 (예정형)
  2. 이렇게 준비하고 있어요: 준비 중인 구성, 소품, 연습, 체험 코너 등. 재료와 대표님 계획에 있는 것 중심이고, 준비하는 분위기는 자유롭게
  3. 이렇게 공연할 예정이에요: 규모, 시간, 진행 방식. 확정된 것만 쓰고 나머지는 "정해지는 대로 알려드릴게요"
  4. 함께하실 분들께: 날씨에 따라 바뀔 수 있는 점 등 재료에 있는 것을 가볍게 한 줄
  5. 마무리: 비슷한 행사를 준비 중이라면 문의 안내 (맨 끝에 문의처)
- **사진**: 준비 과정(소품, 연습)이나 지난 공연 사진. 지난 공연 사진이면 "지난 공연 모습"이라고 밝힌다. `[사진N: 설명]`으로 자리를 표시한다.
- **주의**: 이미 한 것처럼 쓰지 않는다 ("마쳤다", "환호했다" 금지). 일정·장소·인원은 재료대로 쓰고 바뀔 수 있는 것은 예정 표현으로 쓴다. 기관명과 정확한 장소는 공개 행사이거나 대표님이 확인한 경우만.

## 보내기 전 점검표

- [ ] 제목 앞쪽에 지역·대상·공연 종류가 있다
- [ ] 고객이 확인하는 사실(시간·구성·인원·실적·약속)이 재료와 어긋나지 않는다 (애매하면 안전한 표현으로 쓰고 "확인 필요"에 한 줄)
- [ ] 연락처·금액·기관명·정산 정보가 없다
- [ ] '단독 공연' 대신 '콜라보 공연'을 썼고, 같은 공연을 부르는 이름이 글 안에서 오락가락하지 않는다
- [ ] 마크다운 기호 없이 일반 텍스트다 (`scripts/check_draft.py` 통과)
- [ ] 글의 맨 끝에 문의처(전화·이메일)가 있다
- [ ] 사진 자리와 설명이 표시되어 있다
- [ ] 이전 글과 도입·마무리 문장이 겹치지 않는다
